# 🎙️ Voice AI Assistant

An interactive web-based voice assistant application built with JavaScript, HTML, and CSS that interfaces with the Gemini API for speech recognition and voice response synthesis.

## ✨ Key Features

* **Voice Interaction:** Smooth speech-to-text and text-to-speech interaction.
* **Smart Responses:** Powered by Gemini API for intelligent context handling.
* **Clean UI:** Responsive layout designed with custom CSS.

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **API:** Google Gemini API
